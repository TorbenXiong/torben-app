## 新功能

- MySQL、PostgreSQL 和 Redis 实例支持复制连接信息、检测端口、打开数据目录、查看日志和打开数据库 Shell
- 数据库实例继续保留运行、停止、状态检查、备份、恢复和删除能力
- MySQL 默认推荐版本更新为 8.4.11

## 问题修复

- 修复 Windows 首次启动后页面无法进入的问题
- 修复 MySQL 8.4.6 官方下载地址失效导致的版本解析失败
- 修复 MySQL 下载网络中断时无法重试和续传的问题
- 修复数据库实例路径、生命周期和迁移状态处理问题

## 文档

- 更新 MySQL 版本、下载校验和及数据库实例操作说明
- 更新 Windows x64 便携构建与发布流程

## 杂项

- 当前支持平台为 Windows x64
- 便携版无需安装，直接运行 `TorbenApp.exe`
- 当前便携版未进行 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen 提示
- 发布内容只有单文件便携版，不附带安装器、CLI 压缩包或额外校验文件
