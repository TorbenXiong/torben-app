## 新功能

- 新增 Go 插件，支持官方 Windows x64 工具链安装、主版本切换、卸载和外部版本发现
- Go 页面默认展示最近三个稳定 minor 系列，支持精确版本安装及进程级环境变量配置

## 问题修复

- 修复 Go 插件权限校验和历史下载记录缺少 SHA-256 时可用版本为空的问题
- 切换主版本仅更新对应应用的命令 shim，避免其他运行中命令占用文件导致自动选择失败
- 修复旧选择事务回滚后残留回执阻止启动，保留已恢复或外部修改的 shim
- 重复启动显示“Torben App 已运行”，初始化和窗口创建失败显示错误码
- 升级后继续发现已有内置插件，版本查询失败时提供重试入口

## 文档

- 更新 Go 来源、命令与缓存目录说明，以及 Windows 单实例和升级说明
- 补充 Go 安装、自动选择主版本、卸载和旧事务恢复的本地回归测试说明

## 杂项

- 复用现有插件、版本页面与受管库旁暂存逻辑，不新增第三方依赖
- 当前支持平台为 Windows x64
- 便携版无需安装，直接运行 `TorbenApp.exe`
- 升级前请退出现有实例；替换主程序保留 `userData`，已安装插件沿用原版本
- 当前便携版未进行 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen 提示
- 发布内容只有单文件便携版，不附带安装器、CLI 压缩包或额外校验文件
