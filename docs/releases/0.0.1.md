## 新功能

- 支持 Java、Python、Node.js、Rust、MySQL、Redis 和 PostgreSQL 插件
- 支持精确版本安装、多版本共存和主版本选择
- 插件页面和左侧菜单支持拖拽调整顺序
- 支持 Node.js、Java、Python 和 Rust 运行时环境变量
- 支持统一管理 npm、pnpm、pip 和 Cargo 数据目录
- MySQL、Redis 和 PostgreSQL 支持版本管理和实例管理
- 支持数据库实例创建、启动、停止、状态检查、备份、恢复和删除
- 数据库实例固定绑定创建时的运行时版本
- 提供 Windows x64 单文件便携版 `TorbenApp.exe`

## 问题修复

- 修复 Windows 首次启动后页面无法进入的问题
- 修复 canonical path 格式差异导致的递归启动问题
- 修复数据库 shim 被误识别为外部安装的问题
- 修复切换插件后安装或卸载状态显示丢失的问题
- 修复插件排序与左侧菜单不同步的问题
- 修复 MySQL、Redis 和 PostgreSQL 实例数据路径管理问题

## 杂项

- 当前支持平台为 Windows x64
- 便携版无需安装，直接运行 `TorbenApp.exe`
- 发布内容只有单文件便携版，不附带安装器、CLI 压缩包或额外校验文件
