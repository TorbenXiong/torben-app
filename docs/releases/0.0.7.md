## 新增功能

- 新增 Windows x64 CMake 插件，支持官方 CMake 4.2.8 MSI 的版本发现、校验、受管安装、卸载、外部探测和 `cmake` shim 命令
- CMake 插件固定官方下载地址和 SHA-256，并接入桌面插件页、版本目录刷新、便携构建和发布验收
- Java 主版本选择会同步设置系统级 `JAVA_HOME`，让 Launch4j、Digital 等外部程序能够识别当前选中的 JDK

## 问题修复

- 修复 CMake `--version` 输出解析错误导致安装后健康检查失败的问题
- 修复应用升级后仍复用旧版内置 CMake 插件的问题，启动时会刷新已安装的内置插件载荷
- 修复 Java 主版本切换只更新 Torben shim、未更新系统 `JAVA_HOME` 的问题

## 杂项

- 当前支持平台仍为 Windows x64
- 便携版仍为单文件 `TorbenApp.exe`
- 当前便携版未进行 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen 提示
