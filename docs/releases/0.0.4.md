## 杂项

- 合并安装暂存清理逻辑，精简进度筛选，格式检查遵循仓库现有忽略规则
- 当前支持平台为 Windows x64
- 便携版无需安装，直接运行 `TorbenApp.exe`
- 替换主程序保留 `userData`，但不会自动更新已安装的内置插件；新下载和提取逻辑需卸载旧插件后重新启用。已有运行时、主版本或数据库实例引用时仍受卸载保护，处理前应备份相关数据，详见[升级说明](https://github.com/TorbenXiong/torben-app/blob/v0.0.4/docs/china-downloads.md#安装异常与升级)
- 当前便携版未进行 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen 提示
- 发布内容只有单文件便携版，不附带安装器、CLI 压缩包或额外校验文件
