## 新功能

- 新增 7-Zip 插件，支持 Windows x64 官方 `7z` 命令行工具的版本管理、受管安装、卸载和外部版本发现
- 7-Zip 安装计划统一由 Core 生成，固定官方 MSI、SHA-256、健康检查和 `7z` shim 命令
- 中国地区支持 7-Zip 官方发布镜像 fallback，镜像只负责传输，仍执行官方 SHA-256 校验

## 问题修复

- 修复 7-Zip 插件手写安装计划与 Core 校验不一致导致的 `plugin_install_plan_invalid`
- 修复 GitHub 连接失败时 7-Zip 安装无法 fallback 到可用镜像的问题
- 修复合法 GitHub asset CDN 跳转被错误拒绝的问题
- 修复 7-Zip MSI 解包后健康检查错误拼接 `7z.exe` 路径的问题
- 修复 `7z` shim 未被识别为受管别名，导致选择状态读取到错误数据目录并报告 `no_selected_version`

## 文档

- 补充新插件接入时 Core 唯一安装计划来源、协议校验和下载响应来源检查清单
- 更新 7-Zip 软件管理、中国地区下载策略和本地安装回归测试说明

## 杂项

- 当前支持平台为 Windows x64
- 便携版无需安装，直接运行 `TorbenApp.exe`
- 升级前请退出现有实例；替换主程序保留 `userData`，已安装插件沿用原版本
- 当前便携版未进行 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen 提示
- 发布内容只有单文件便携版，不附带安装器、CLI 压缩包或额外校验文件
