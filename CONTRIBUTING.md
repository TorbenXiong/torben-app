# Contributing

Thank you for contributing to Torben App.

## Development flow

1. Create a focused branch from `main`.
2. Keep changes scoped and add tests for behavior and rollback paths.
3. Run the Rust and frontend checks documented in `README.md`.
4. Open a pull request. Do not push directly to protected branches.

## Commit messages

Use a concise Conventional Commits-style title and explain non-obvious behavior or migration impact
in the body. DCO sign-off trailers are not required.

## Security issues

Do not open a public issue for a suspected vulnerability. Follow `SECURITY.md` instead.
